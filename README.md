# Personal Portfolio

A personal portfolio site built with React, TypeScript, Vite, React Router, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run oxlint

## Structure

- `src/pages` — route-level pages (Home, About, Projects, Project detail, Contact)
- `src/components` — shared layout, nav, and footer
- `src/data` — placeholder content (`projects.ts`)
